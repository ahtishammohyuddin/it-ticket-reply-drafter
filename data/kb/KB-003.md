# Set up MFA on a new phone
Category: password_login
If you have changed phones, your authenticator app needs to be moved.
1. If you still have the old phone, open the security portal at https://mysecurity.example.com and add the new phone first, then remove the old one.
2. If the old phone is lost or wiped, the service desk can issue a temporary access pass after identity verification by video call or in person.
3. Install the company authenticator app on the new phone and scan the QR code shown in the portal.
Never share a verification code with anyone, including the service desk.
