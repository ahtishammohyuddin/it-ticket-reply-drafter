# Request new software
Category: software
1. Check Software Center first. Approved software installs there without a ticket.
2. If the software is not listed, submit a software request with the name, version, business reason and whether a licence is needed.
3. Your line manager approves the request, then the security team reviews it.
4. Once approved, the software is added to Software Center for you.
Do not install software from the internet yourself. Laptops block unapproved installers.
