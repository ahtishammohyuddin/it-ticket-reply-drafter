# Recover a deleted file
Category: other
1. Check the Recycle Bin on your laptop and restore the file if it is there.
2. For files on your cloud drive, open the cloud drive in a browser and check its recycle bin. Deleted files stay there for 93 days.
3. For a shared folder, right-click the folder, choose Restore previous versions, and pick a version from before the deletion.
4. If a large amount of data is missing or several people are affected, report it straight away so backups can be checked before they rotate.
