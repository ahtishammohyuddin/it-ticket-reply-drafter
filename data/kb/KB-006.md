# Printer not printing
Category: hardware
1. Check the printer screen for paper jams, empty trays or low toner.
2. Make sure you selected the correct printer. Office printers are named by floor, for example FL2-PRINT-01.
3. Open the print queue on your laptop, cancel stuck jobs, and print again.
4. Restart the laptop, which reconnects to the print server.
5. If nobody on the floor can print, report it so a technician can check the device.
