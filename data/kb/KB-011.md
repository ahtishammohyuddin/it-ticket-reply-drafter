# Office Wi-Fi problems
Category: network_vpn
1. Connect to the network named CORP-WIFI using your work username and password. GUEST-WIFI does not reach internal systems.
2. If you recently changed your password, choose Forget network on CORP-WIFI, then connect again with the new password.
3. Turn Wi-Fi off and on, or restart the laptop.
4. If only one area of the office has no signal, note the location so the network team can check the access point.
